# A client app for T-Shirt Shop based on Next.js

## Usage

```bash
npm install
npm start:dev
```

## Deploy to Heroku

### Manual

Using Node,js buildpack

```bash
heroku buildpacks:add --index 1 heroku/nodejs
```
